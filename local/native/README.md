# Native Windows backend profile

These explicit loopback-only profiles preserve the same Collector capture processors as the container configuration. Jaeger enables only memory storage and query, with no sampling, profiling, AI agent or MCP extension. The lab proof runner verifies the pinned packages, generates bounded file captures privately, and owns start/stop. See [the lab runbook](https://github.com/AI-SRE-Oberveability/ai-observability-lab/blob/work/local-backend-proof/docs/local-backend-runbook.md). No cloud/live-model or Managed result follows from this profile.
